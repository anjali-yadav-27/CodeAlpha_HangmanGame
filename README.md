
# CodeAlpha Hangman Game

## About the Project
This is a simple text-based Hangman game developed
using Python as part of the CodeAlpha internship.

## Features
- Random word selection
- Five predefined words
- Maximum six incorrect guesses
- Input validation
- Win and lose conditions

## Technologies Used
- Python 3
- random module
- Loops and conditional statements
- Strings and lists

## How to Run
1. Install Python 3.
2. Open the terminal in the project folder.
3. Run the following command:

   py hangman.py
